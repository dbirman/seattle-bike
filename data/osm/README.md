# OpenStreetMap extract

`seattle-highways.geojson` is generated by `npm run data:fetch` from OpenStreetMap's Overpass API. The current query covers the Seattle-area bounding box `47.49,-122.45,47.75,-122.22` and keeps bike-relevant streets plus explicitly bicycle-designated paths. This rectangular coverage includes some nearby areas and is not an administrative city-boundary clip.

`public/data/seattle-highways.geojson` is clipped to that same approximate city rectangle. Build it from the existing local extract with `npm run data:build`, or refresh the source and both browser extracts with `npm run data:fetch`.

`public/data/seattle-reachability.json` stores green-reachable distance for every road segment in the Seattle extract. Generate it after building roads with `npm run data:precompute`. The cache is keyed to both the road data and risk config; the app ignores it if either changes.

`public/data/seattle-routing-graph.json` and `.bin` store the fingerprinted routing graph used by click-to-view comfort. Generate both with `npm run data:precompute-graph`, or together with reachability using `npm run data:precompute`. The app downloads and hydrates the graph only when comfort mode is selected.

`public/data/fremont-highways.geojson` remains as a small test extract clipped to `47.648,-122.387,47.672,-122.357`.

The data is © OpenStreetMap contributors and available under the Open Database License (ODbL) 1.0. The app displays the required OpenStreetMap attribution for both its road data and raster tiles.
